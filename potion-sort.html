Potion Sort

Pour the potions until every flask holds a single color.

Potions brewed!

Level 1 Moves 0

How to play

  • Tap a flask to pick it up, then tap another flask to pour into it.
  • You can only pour onto the same color, or into an empty flask.
  • Each flask holds four layers. Fill every flask with one color to win.
  • Stuck? Use Undo, or add one extra empty flask per level.
